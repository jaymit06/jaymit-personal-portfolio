# Jaymit Shriyan — Personal Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript.

## About

This site introduces Jaymit Shriyan, a B.Tech Data Science student at NMIMS, Mumbai, and showcases selected projects, technical interests, creative practice, and contact information.

## Projects featured

- **Legal Document Review Assistant** — a learning project exploring AI-assisted review of legal documents.
- **Spotify Popularity Predictor** — a machine-learning project exploring patterns associated with track popularity.
- **Exoplanet Mass–Radius Predictor** — a regression project exploring the relationship between exoplanet mass and radius.

See the portfolio for project descriptions and links to the individual repositories.

## Run locally

Download or clone this repository, then open `index.html` in a browser. No build step or package installation is required.

## Deployment

The site is published with GitHub Pages. If you fork or reuse this project, you can enable it from **Settings → Pages**, choose **Deploy from a branch**, then select the `main` branch and `/(root)` folder.
